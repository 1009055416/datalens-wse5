# 数据透镜 DataLens

本地数据分析 Web 应用：打开 CSV，自动识别字段类型，生成统计卡片、交互图表（柱状 / 直方 / 饼图 / 折线 / 散点 / 相关性热力图）与自然语言数据洞察，支持导出 PNG 图表与 Markdown 报告。全部数据仅在本机浏览器内处理。

- 直接打开 `index.html` 即可使用（Chrome / Edge），无需构建、无第三方依赖。
- 支持 UTF-8 / UTF-16 / GBK 编码，逗号 / 分号 / Tab / 竖线分隔的 CSV。
- 内置三套示例数据，首次打开自动载入。
